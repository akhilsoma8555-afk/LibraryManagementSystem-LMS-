Library Management System (Java)

A simple Java-based Library Management System that allows users to add books, issue books, return books, and maintain records using file handling (TXT files).
This project was developed as part of my Practicum.

🔹 Features

Add new books

View available books

Issue a book to a student

Return a book

Search for a book

Validate book availability

Store book and student details in text files

Menu-driven program

Lightweight and easy to understand

🔹 Technologies Used

Java

File Handling (books.txt, students.txt)

Command-Line Interface

🔹 File Structure
LibraryManagementSystem.java
books.txt
students.txt

🔹 How to Run

Install Java JDK (8 or above)

Open terminal/command prompt

Navigate to the project folder

Compile the program:

javac LibraryManagementSystem.java


Run the program:

java LibraryManagementSystem
